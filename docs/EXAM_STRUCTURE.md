# 本番の出題構造の分析（2026-08-31）

公式テキスト `text_ocr/AICX_official_text.md` に載る**理解度チェック98問**を機械計測した結果。公式テキスト自身が L155・L161 で「各Sectionは、知識 → 業務シナリオ → 理解度チェックの流れ」「理解度チェックでは、知識と判断のポイントを**試験形式で**確認します」と書いており、本試験の出題形式を反映しているとみなす。

**問題数は98問**（60問ではない）。設問マーカーの表記が5種類混在しており（`**問N**` 60件 / `### 問N` 15件 / `問N　` 23件 ほか）、`**問N**` だけを数えると60問になる。**この取りこぼしで一度誤った分析を出した**（下の「訂正の記録」）。

| 問題文 中央値 | 87字 | 53字 |

**単純な長文化は不要。** 公式でも「長文」と呼べるのは Section24 の2問（877字・656字）だけで、これは例外的な難度帯。字数を増やす方向の改修は間延びを生むだけで効果がない。

**唯一の実質的な差は問題文（状況設定）の厚さ**＝公式87字 vs サイト53字。公式は状況を厚く書き、選択肢は短く締める。サイトは逆。

**留保**: 公式テキストの理解度チェックが1問219字なら50問75分は余裕のはずだが、受験者は全員「時間が足りない」と証言している。本試験は理解度チェックより長いと考えるのが自然で、公式の `業務シナリオ` ブロック（30箇所・中央値121字）を設問へ畳み込む形式なら1問340〜380字になる。**これは推測**。

## 2. 公式の長さは何で生まれているか

かく乱目的の無関係情報は**ほぼ存在しない**。問題文が長い問を実読した結果、字数は次の3つで生まれている。

1. **分類対象の項目列挙**（X/Y/Z をカテゴリへ一斉割り当て。24問がこの型）
2. **誤答選択肢の根拠になる事実を本文側に先出し**する（L2492 の6ステップは、正解以外の5ステップが誤答肢A/C/Dの素材そのもの）
3. **各選択肢に「結論＋理由」を書く**

L6552（最長877字）は3部門の相反する事情＋CFOの異論＋前回CoEの失敗を並べ、**記述を1つ落とすと正解が変わる**。捨てられる記述がない。

→ 長文化するなら「読み飛ばせる描写」を足すのではなく、**各記述が特定の選択肢に対応する**ように書く。

## 4. 公式が明かす「引っかかり方」（98問中14問の解説に記載）

想定されている誤解は3つ。

1. **統制の言葉への過剰反応** — 「遵守を求める」「事前承認」「義務付け」を見た瞬間に不適切と判断してしまう（L6594 は誤答肢3つすべてがこの罠）
2. **配慮ある案の過大評価** — 「段階的に」「まず〜してから」が現実的に見えるが、その空白期間自体がリスク（L6552-D を公式が「最も巧妙な誤答」と明記）
3. **権威ある根拠への追従** — 監査法人・CFO・経営層の要請という「正解に見える根拠」が誤答肢の側に置かれる

## 6. 問い方の語彙（98問）

「最も適切なものはどれですか」49問が主流。**否定形（最も不適切・誤っている）は5問（5.1%）**で、いずれも「正しい記述を3つ並べて1つだけ外す」構成。その5問の誤答肢の型は例外なく「記述自体は正しいが設問の条件に合わない」。

## 訂正の記録

このファイルの初版を書く前に、監督が2度誤った数字を出した。原因と対策を残す。

1. **「公式は60問」** → 実際は98問。`**問N**` 形式だけを grep していた。**表記ゆれのあるテキストを数えるときは、まず表記のバリエーションを数え上げる**
2. **「公式の問文中央値391字・サイトは53字で300字以上が0問」** → 誤り。選択肢が `- A.` 形式の問で選択肢まで問題文として数えていた。正しくは公式87字・サイト53字で、1問合計ではほぼ同規模。**問題文と選択肢を分離せずに「長さ」を語らない**

いずれも「サイトを長文化すべき」という誤った結論を導きかけた。**計測の前にパースの正しさを検証する。**
