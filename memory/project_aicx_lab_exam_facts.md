2026-08-31 に web 調査で確定。それまで DESIGN §7 で「50問/100点/8割は代理指標」としていたが、**出題数と時間は実測値と一致していた**。

| 項目 | 内容 | 確度 |
|---|---|---|
| 出題数 | **全50問** | 実受験者の記事と対策サイトで一致 |
| 試験時間 | **75分**。「時間にほとんど余裕がない」 | 複数ソース一致 |
| 満点 | 100点 | 1ソース |
| 合格ライン | **非公開**（AICX協会は公表していない） | 受験者が SNS 観察で「70点以上で合格が複数」と推測 |
| 第1回合格率 | **39.8%**（1,137名受験 / 452名合格） | 実受験者の記事 |
| 出題形式 | 4択の多肢選択式 | 複数ソース一致 |
| 問題の質 | **「1問が長いケース問題」。基礎問題とケース問題が全体の約8割** | 実受験者の記事 |
| 受験環境 | 自宅IBT。不正防止が厳格で、タブ・ウィンドウ切替やページ離脱の履歴を監視。ブックマーク操作でもアラート | 実受験者の記事 |
| 受験料 | 14,800円（税込） | 対策サイト |

**HK が受験者から直接聞いた話（2026-08-31）**: 「基本的に全部が長文読解。50問75分で時間が足りない理由は、その読解に時間を要するから」。web の記述と整合する。

## 未確認：ケースの構造（これで作るものが変わる）

無料公開の予想問題（[中堅都市ガス会社ケース](https://ai-agent-master.com/mock-exam-utility-1/)）は **1ケース1,200〜1,500字に設問5問がぶら下がる**構造。ケース本文には企業概要・問い合わせ5分類の件数比率・As-Is 8ステップ・課題4つ・ステークホルダー8名の懸念が並ぶ。設問は「最初に検討すべき改善案として最も適切なものはどれか」「MVPとして最初に着手するスコープとして最も適切なものはどれか」など。

ただし**これは第三者の予想問題であって公式の構造ではない**。実受験者の記事は「1問が長いケース問題」と書いており、1問1ケースとも読める。**HK が受験者に確認中**。

- 1ケース1問なら → 既存問題の設問を長文化するだけ
- 1ケース複数問なら → **ケース共有型という新しい問題形式**が要る（データ構造も画面も変わる）

## サイトとのギャップ（2026-08-31 時点）

- **模試125問中ケース問題は1問だけ**。ケースは22問あるが全部 `pool:'both'`（レッスン所属）で、模試の「lesson 再利用は15問まで」の枠に阻まれて入らない
- ケース本文は中央値198字・設問文は中央値48字。本番の「長文読解」には短い
- 第1章の Sec1・2・3 が各2問と薄い

## HK の方針（2026-08-31）

**「まず知識、その上で長文」。** 知識が入っていない段階で長文を解いても読解の練習にならない。よってレッスンの短文問題は知識定着用として残し、長文化は仕上げ用として別に足す。全問長文化はしない。
