AICX公式テキスト（画像PDF・401ページ）を全文書き起こし、二重キー入力方式で検証した。成果物は **`text_ocr/`（git 管理外）**。

## 成果物

| パス | 内容 |
|---|---|
| `text_ocr/AICX_official_text.md` | 全401ページ結合版。各ページに `<!-- p308 \| 印字ページ番号: 295 -->` のアンカー |
| `text_ocr/png/pXXX.png` | 全ページ画像（1800px）。**原文確認はここを見る** |
| `text_ocr/md/` | A版（マスター） / `md_b/` B版（検証用の独立2回目） |
| `text_ocr/VERIFICATION.md` | 検証レポート全文 |

元PDFは Google Drive がローカルマウントされている `G:\マイドライブ\AIエージェント・ストラテジスト資格\`（20ファイル・約730MB）。ダウンロード不要。

## 恒久ルール（最重要）

**この書き起こしは「検索・照合の道具」であり「最終根拠」ではない。** 教材や問題を実際に書き換えるときは、根拠ページの `text_ocr/png/pXXX.png` を開いて原文を確認してから直す。ページアンカーはそのための足。

理由: (a) 図の細部（凡例・小さな注記）は HK 決定により意図的に落としている (b) A版とB版が同じ誤読をする穴は狭めたが塞ぎきっていない。

## 信頼度

- 401ページ全部でA版・B版のページ割り当てが一致
- 印字ページ番号アンカー46点すべてで「配列順位 − 印字番号」= +1（PDFページ = 印字+1）。欠落・重複・順序入替えゼロ
- 監督が無作為20ページ＋要注意14ページを画像と全文照合し不一致ゼロ

## 検証の到達点（2026-08-29 に残課題を全て解消）

三重化で完了。①A版 ②B版（独立2回目） ③**Tesseract による第3の独立検証（401/401 完走）**。
③は全文一致率ではなく数値・英字略語だけを照合する設計（写真の漢字認識が弱いため）。
要確認35件を全件裁定し、**マスター側の欠陥はゼロ**（35件すべてTesseractの誤読）。

| 旧・未解決 | 決着 |
|---|---|
| Tesseract が 83/401 で未完走 | **401/401 完走・欠陥ゼロ** |
| 図の細部が未収録 | 方針は維持し、`text_ocr/FIGURES.md` に所在を索引化（図表192点／173ページ、図主体24ページを優先確認） |
| p398 の図中ラベルが未確定 | **「処理時間」で確定**。根拠は図ではなく p396 の本文（A/B一致率1.0） |

## 順序の保証（アンカーの空白と、その埋め方）

印字ページ番号アンカーは46点しか取れず、順位3〜102・105〜202に大きな空白がある。
前半の写真は**PDFビューアをスクロールした画面の撮影で、紙面下端のノンブルが画角に入っていない**ため増やせない
（専用OCRを組んで較正したが既知46点中19点しか当たらず、原因が「そもそも写っていない」ことだと判明した）。

代替として本文側の連番で裏付けた: **CHAPTER 1〜6・Section 1〜27 の見出しが配列順に厳密昇順・欠番なし**。
第6章は Section 番号ではなく5Dの段階名が見出しなので、その5つも出現順が正しいことを確認済み。

## 透かし（購入者情報）の扱い — クローズ済み

PDF全ページに購入者を特定する透かし（HK 本人ではない別名義のメール・氏名）が焼き込まれている。
**入手経路は会社購入・正式シェアと HK が確認済み（2026-08-29）。以後この透かしを理由に入手経路を再確認しない。**

透かし文字列は書き起こしに残さない。混入していた8行（`AICX_official_text.md` 3 / `md/` 3 / `adjudicate/` 2）は除去済みで残存ゼロ。
png は焼き込みのため除去不可だが git 管理外。`tools/verify3.py` の STOP でも除外しており、第3検証で毎回ノイズとして出るのを防いでいる。
