**作業（実装・ファイル編集）に入る前に、何をやるかを HK に伝えてから着手する。** 2026-08-28 に HK が明示要求（「今度から作業に入る前に教えて」）。

グローバルの「自律作業モード（都度の承認・確認なしで進めてよい）」を**部分的に上書きする**。承認待ちで止まれという意味ではなく、**着手前に一言、対象と内容を宣言する**という運用。宣言してから続けて着手してよい。

**Why**: HK は非エンジニアで、Claude が何を触っているかを見て把握したい。事後報告だけだと、意図と違う方向に進んでいても途中で止められない。実際このセッションでは Build を4本連続で実装し、HK は完了報告でしか内容を知れない状態だった。

**How to apply**: Build 着手時は「次は Build {ID}（{1行の内容}）。着手します」を先に出す。複数の選択肢がある場合や、HK の指示から複数の解釈が成り立つ場合は、宣言して GO を待つ。単発の調査・質問への回答には適用しない（作業ではないため）。

**適用範囲**: 現時点では aicx-lab での要求。全プロジェクトへ広げるなら `~/.claude/CLAUDE.md` の「作業スタイル」へ移すが、HK の明示指示がないうちはこのプロジェクト内にとどめる。
